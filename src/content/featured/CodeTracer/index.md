Agent-driven DSA visualizations with a fullstack coding platform. Features a real-time contest system with live leaderboards, a full social layer (friend requests, presence, direct messaging), and secure C++ code execution via Judge0 in sandboxed environments. An in-built AI coaching agent dynamically renders algorithm visualizations (arrays, graphs, trees) through agent-controllable React components, powered by a Web Worker-based execution engine with a custom Tracer class API connecting agent-generated code to animated playback.
